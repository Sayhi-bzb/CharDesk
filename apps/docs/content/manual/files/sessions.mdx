## Saving in the browser

Web Canvas automatically saves to local storage in your current browser. Use the session list to switch between canvases.

Different browsers, browser profiles, and website addresses can use separate storage, even on the same device. Clearing site data affects local canvases. [Export important work](/files/import-export/) separately; autosave is not a backup across devices.

## Saving in the terminal

The terminal automatically saves local sessions and restores the workspace on later launches. It uses your operating system's application data directory and does not automatically sync with browser sessions.

On macOS, canvas data lives in `~/Library/Application Support/chardesk`. Windows uses local AppData; Linux defaults to `~/.local/share/chardesk`. If you configured a custom data directory, use that location.

## Switch, close, and archive

Switch or rename canvases in the session panel. Closing a session removes its current workspace entry; it is not a way to destroy backups. Archive content you do not need in the active list.

Before deleting or removing anything, check the target and the action's description. Export important canvases before reorganizing them.

## Continue on another device

Export a file and open it on the other device, or use [collaboration](/collaboration/). Copying a normal page URL does not transfer all canvases stored in your browser.
