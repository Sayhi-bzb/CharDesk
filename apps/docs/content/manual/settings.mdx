## Appearance and language

Open settings to choose a theme and language. Web Canvas and the terminal save their own local preferences. Opening the same file does not sync every setting.

Themes affect reading and interface appearance. Explicit canvas colors remain unchanged; see [Colors and styles](/editing/style/).

## Shortcuts

Check the current interface's shortcut hints and help. macOS uses a different primary modifier from other platforms, and terminal shortcuts depend on what the terminal forwards.

If a shortcut does not respond, try the corresponding button, then check focus and terminal bindings. A missing key response alone does not mean the feature is unavailable.

## Text rendering

Rendering settings affect future pastes or conversions, not content already on the canvas. Try a short sample before applying a different setting to longer content.
