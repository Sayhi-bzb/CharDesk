## Local Agents

Use Local MCP when your Agent runs in a client that can start an MCP server, such
as a coding assistant. It connects that Agent to [Web Canvas](/canvas/).

Add CharDesk as a local MCP server with this launch command:

```sh
npx -y @chardesk/mcp
```

Configuration differs by client. Save the server configuration, then start the
client and open [CharDesk Canvas](https://canvas.chardesk.com/). The page normally
discovers the local connection without manual pairing. If the Agent calls a
Canvas tool before a page is open, CharDesk can open Canvas and ask it to retry.

Check connection status and permissions in **Agent → Local MCP**. Enable the
reading, searching, or writing access needed for the task.

## Browser Agents

For an Agent working inside a supported browser, use [WebMCP](/agents/webmcp/).
That path discovers tools from the open page instead of launching this local server.

## Confirm the connection

Ask the Agent to read the current canvas and describe its content. Confirm the
target, then ask it to add a short passage and read it back. You should see the
change on the same canvas.

Install the [Skill](/agents/skill/) for authoring guidance and follow
[Agent workflow](/agents/workflow/) for larger edits. To operate on terminal
sessions or local files, use the [CLI](/cli/); this browser connection does not
automatically target the TUI workspace.

For connection failures, see [Agent cannot connect](/troubleshooting/#agent-cannot-connect). The [MCP reference](https://github.com/Sayhi-bzb/CharDesk/tree/main/packages/mcp#readme) owns installation and advanced configuration.
