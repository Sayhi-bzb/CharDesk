## Open your workspace

Open [CharDesk Canvas](https://canvas.chardesk.com/). Explore the welcome canvas,
then create your own from the session menu. No local command is needed for manual
browser editing.

Content sits on a character grid. Put related ideas below one another and
comparisons side by side. Panning changes your view without moving the content.

## Create your first canvas

1. Select the text tool, click an empty spot, and type a title.
2. Click below it or to the right to add another passage.
3. Switch to the selection tool, drag out a range, and move, copy, or recolor it.

Use [Typing and pasting](/editing/input/), [Selection](/editing/selection/),
[Colors and styles](/editing/style/), and [Finding content](/editing/search/)
for the editing controls.

## Work with an Agent

Use [Local MCP](/agents/connect/) for a local Agent client or
[WebMCP](/agents/webmcp/) for a supported browser Agent. The
[Skill](/agents/skill/) gives your Agent the authoring guidance.

Ask the Agent to read the intended canvas before making a change, then inspect
the result together. [Agent workflow](/agents/workflow/) covers continuing edits.

## Save and share

Browser canvases save automatically in the current browser. [Sessions](/files/sessions/)
explains where they live and how to resume them. Use [Import and export](/files/import-export/)
for an editable copy or an image, and [Collaboration](/collaboration/) to work with
another person.

For a terminal workspace, use [Terminal canvas](/terminal/). Browser and terminal
sessions have separate storage; opening the same product does not synchronize them.
