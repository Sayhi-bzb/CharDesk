## Choose where to work

| What you want to do | Start here |
| --- | --- |
| Create with an Agent | [Skill](/agents/skill/) |
| Connect a local Agent | [Local MCP](/agents/connect/) |
| Use a browser Agent | [WebMCP](/agents/webmcp/) |
| Edit in your browser | [Web Canvas](/canvas/) |
| Edit in your terminal | [Terminal](/terminal/) |
| Automate local files | [CLI](/cli/) |

Skill supplies authoring guidance; MCP and WebMCP supply access to a browser canvas.
CLI commands operate on local files and terminal sessions. Choose the target before
starting: browser and terminal sessions do not automatically share storage.

## Start with your Agent

Install the [CharDesk Skill](/agents/skill/), then connect through
[Local MCP](/agents/connect/) or [WebMCP](/agents/webmcp/). Ask for a first result:

```text
Use CharDesk to explain how a GPU works as a visual canvas.
Read the result and check the layout before finishing.
```

Use [Agent workflow](/agents/workflow/) to describe placement, review changes,
and continue editing the same canvas.

## Open a canvas

Choose [Web Canvas](/canvas/) for browser editing and sharing, or
[Terminal canvas](/terminal/) for a local workspace in your terminal.

## Add your first content

Start with a short title and a related passage below it. Follow
[Typing and pasting](/editing/input/) and [Selection](/editing/selection/) to edit
by hand, or ask your Agent to add content next to an existing passage.

See [Sessions](/files/sessions/) for saving and recovery, and
[Import and export](/files/import-export/) to keep an independent copy.
