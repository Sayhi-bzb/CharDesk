title: Typing and pasting

## Type text

Select the text tool, click a starting position, and type. A line break continues on the next row. CJK characters and emoji may occupy two cells while remaining one complete character.

Switch to Hand to pan, then return to the text tool to keep typing. In the terminal, Edit handles both typing and selection; the default Hand mode pans the view.

## Paste content

Choose a position, then paste. Web Canvas uses the shared text renderer to turn Markdown, ANSI, and other supported input into editable canvas characters. The result depends on your rendering settings.

To preserve indentation and symbols in character art, use literal text mode or wrap it in a plain Markdown code block. Do not paste coordinate rulers from an Agent's canvas readout as content.

## Adjust pasted content

Pasted characters can be selected, moved, and styled. Changing rendering settings does not reinterpret existing content. Undo and paste again to apply different settings.

See [Selection](/editing/selection/) for copying, cutting, and moving a range.
