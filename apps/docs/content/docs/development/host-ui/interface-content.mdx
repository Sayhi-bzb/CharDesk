---
title: Interface Content
description: Contract for visible Host and widget copy.
---

- Give a surface one visible title; add description only for a constraint,
  consequence, safety fact, or non-obvious interaction.
- Do not restate a label, highlighted target, state, or action in adjacent copy.
- Keep `canvas`, `session`, `slide`, `selection`, `cut`, and `paste` stable.
- The shortcut surface owns shortcut guidance; other surfaces link to it.
- Localize product operation labels together in English and Chinese. User,
  document, and template labels retain their source value.
- Brevity does not remove accessible names, destructive consequences, security
  facts, or screen-reader instructions.
