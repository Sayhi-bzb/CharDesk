## Knowledge ownership

[Repository documentation rules](https://github.com/Sayhi-bzb/CharDesk/blob/main/AGENTS.md) own writing policy. Document project-specific constraints, decisions, and evidence; omit general engineering tutorials. A navigation summary links to its owner rather than becoming a second contract.

| Knowledge | Authority |
| --- | --- |
| Product entry and examples | Root `README.md` and `README.zh-CN.md` |
| Live Canvas/Slide authoring | [CharDesk skill](https://github.com/Sayhi-bzb/CharDesk/tree/main/.agents/skills/chardesk) and references |
| MCP installation and local bridge lifecycle | [MCP package README](https://github.com/Sayhi-bzb/CharDesk/blob/main/packages/mcp/README.md) |
| Package installation and public API | Owning package README; Cell UI consumption uses [its public portal](https://ui.chardesk.com/) |
| User workflow | `docs/user` |
| Cross-module decisions and contracts | `docs/development`; [domains](/development/domains) own capability routing, [ownership](/development/architecture/ownership) owns dependency direction |
| Implementation and verification | Linked source and nearest tests |
| Commands and dependencies | Root [package.json](https://github.com/Sayhi-bzb/CharDesk/blob/main/package.json) |
| Research and history | `apps/docs/research` and Git; neither overrides the current contract |

Each page starts with four routing rows: task trigger, direct answer, owner/boundary, and follow-up. Keep an answer in the first block; put contracts and evidence below it. Preserve code identifiers and stable URLs when shortening prose.

## Publication

[`agent-routes.json`](https://github.com/Sayhi-bzb/CharDesk/blob/main/apps/docs/content/agent-routes.json) owns task routing. The website's Development table and Agent route map are generated from it. Its keywords, identifiers, exclusions, and follow-ups remain in JSON; the reading index emits only task and destination.

[`source.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/apps/docs/app/lib/source.ts) owns the source split: all pages feed the website and search; development pages also feed Agent Markdown.

| Output | Reading scope |
| --- | --- |
| `/llms.txt` | Compact task map and page links |
| `/llms.mdx/development/.../content.md` | One selected contract |
| `/llms-full.txt` | All development contracts; opt in when the task spans them |
| `/agent-routes.json` | Rich machine-readable routing metadata |

[`verify-build.mjs`](https://github.com/Sayhi-bzb/CharDesk/blob/main/scripts/docs/verify-build.mjs) checks generated views, search, metadata, internal pages and anchors. The [reading-budget benchmark](/development/quality#agent-navigation) measures index-plus-contract tokens against a fixed baseline. Builds never advance the [reviewed source revision](/development/delivery#documentation-freshness).
