## Compilation contract

`source + format + render options → fragments → Protocol rows → host`

[`compiler.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/packages/chargraph/src/compiler.ts)
owns request normalization and row compilation. Canvas, MCP material rendering,
CLI, Viewer, document import, and legacy source adapters share this boundary.
Native document envelopes and copied Cells bypass format detection. Rendering
paints compiled documents; it does not select syntax.

Explicit `format` overrides legacy `sourceKind` and `chargraphMode`. `raw` aliases
`plain`; legacy `chargraph` selects Auto unless `chargraphMode` is provided.
An explicitly requested Auto overrides the Canvas profile; omitted formats use
the host default. Equivalent normalized requests produce equivalent output;
host defaults for theme and wrapping may differ.

| Format | Interpretation |
| --- | --- |
| `plain` / `raw` | Literal symbols, indentation, and line boundaries; no syntax recognition. |
| `ansi` | Protocol ANSI decoding; Markdown markers remain literal. |
| `markdown` | Markdown and registered extensions; explicit ANSI styles may compose with semantic styles. |
| `auto` | Explicit ANSI selects ANSI-only rendering; otherwise classify and render blocks as below. |
| `chardesk` | Compiled ESC-less ANSI; terminal ESC bytes are rejected. |

## Auto block policy

[`markdown.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/packages/chargraph/src/markdown.ts)
uses Markdown syntax boundaries; box-drawing glyphs and punctuation density do
not select a literal format. Unfenced text keeps inline Markdown semantics,
including bold labels inside flowcharts.

Use an ordinary fenced code block (no language or `text`) to preserve a character
diagram's indentation and Markdown-looking punctuation. Indented code follows
Markdown's indentation rules. Registered fenced languages retain their renderers.
Paragraphs without syntax evidence preserve their text and source spacing;
adjacent Markdown still renders.

The old `|||` field layout, layout-row grammar, parser exports, and layout options
are removed. `|||` is ordinary text; `---` follows the selected format's grammar.
CLI inspect uses the rendered grid, without a separate layout reading projection.

## Styles, fallback, and scheduling

Auto does not activate ANSI on an ambiguous ESC-less empty reset (`[m`) alone.
Forced ANSI accepts it. In explicit Markdown, ANSI foreground, background, and
OSC 8 href override semantic styles; attributes merge. Unsupported or bounded-out
extensions preserve their corresponding source and report diagnostics.
`pipeline` records applied decoder and renderer stages. Source origins refer to
the input, including CRLF offset restoration.

Protocol alone owns grapheme segmentation, CJK width, tabs, and coordinates.
Fragments are the styled intermediate representation; ANSI serialization is an
output boundary. Theme, feature, and wrapping ownership belongs to
[rendering features](/development/architecture/text-rendering-features).

Canvas main-thread and Worker rendering receive the same context and profile.
The 50,000-character scheduling threshold does not change format policy. Worker
failure is reported; it does not trigger a blocking main-thread retry. Settings
apply to future conversion and never reinterpret stored Cells. `canvas_write`
remains a literal stroke with transparent spaces.
