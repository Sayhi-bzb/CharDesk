Load the invariant that selects the implementation and nearest deterministic test:

| Concern | Project invariant | Authority and evidence |
| --- | --- | --- |
| ANSI/Unicode text and Canvas cells | This is the LLM–human communication boundary; syntax, cell layout, Canvas adaptation, and serialization form one semantic round trip. | [LLM–Human Text Protocol](/development/architecture/ansi-canvas-protocol) |
| Canvas coordinates | `@chardesk/rendering` owns Cell/viewport projection. Anchored zoom preserves the screen anchor; host snapping resolves a wide grapheme to its leading cell. | [`viewport.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/packages/rendering/src/viewport.ts), [`coordinates.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/widgets/canvas-editor/hooks/interaction/core/coordinates.ts), and [`canvas-coordinates.test.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/widgets/canvas-editor/hooks/interaction/core/canvas-coordinates.test.ts) |
| Frame and render scheduling | One scheduler coalesces keyed work and unions layer invalidation bits. Render inputs invalidate only the affected background, scratch, or overlay layer. | [`FrameScheduler.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/widgets/canvas-editor/engine/FrameScheduler.ts), [`CanvasRenderManager.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/widgets/canvas-editor/engine/CanvasRenderManager.ts), [scheduler tests](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/widgets/canvas-editor/engine/FrameScheduler.test.ts), and [render tests](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/widgets/canvas-editor/engine/CanvasRenderManager.test.ts) |
| Camera and edge scroll | The camera owns imperative viewport queues, constraints, and animation cancellation. Fit consumes viewport insets; eligible edge drag pans through the shared frame scheduler after its delay. | [`CanvasCameraManager.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/widgets/canvas-editor/engine/CanvasCameraManager.ts), [`CanvasEdgeScrollManager.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/widgets/canvas-editor/engine/CanvasEdgeScrollManager.ts), [camera tests](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/widgets/canvas-editor/engine/CanvasCameraManager.test.ts), and [edge-scroll tests](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/widgets/canvas-editor/engine/CanvasEdgeScrollManager.test.ts) |
| Static-grid selection | `@chardesk/cell-core` owns range normalization, row spans, clipping, and Cell-footprint expansion. The Selection domain owns active-cell and product transitions. | [`range.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/packages/cell-core/src/range.ts), [`static-grid.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/selection/model/static-grid.ts), and [`staticGridModel.test.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/selection/staticGridModel.test.ts) |
| Static-grid text input | A local input session owns its explicit origin. Enter and bounded wrapping return to that column; Cell content never implies a line or paragraph. | [`static-grid-input-session.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/selection/model/static-grid-input-session.ts) and [`staticGridInputSession.test.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/selection/staticGridInputSession.test.ts) |
| Static-grid deletion | One directional delete plan resolves Range priority, Cell targets, wide-grapheme anchors, and finite bounds. Canvas applies the plan as one document mutation and interaction transition. | [`static-grid-deletion.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/selection/model/static-grid-deletion.ts) and [`staticGridDeletionCommands.test.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/canvas/state/staticGridDeletionCommands.test.ts) |
| Slide deck and bounds | Sizes use positive integer columns and rows. Grid normalization canonicalizes, deduplicates, sorts, and removes overflow; resize reports and crops cells outside the new finite bounds. | [`grid.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/slides/grid.ts), [`deck.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/slides/deck.ts), and [`slides.test.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/slides/slides.test.ts) |
| Retired Structured input | Legacy nodes are decoded and rendered once into deterministic CellPlane entries. No scene identity, layer behavior, or collaboration contract survives migration. | [`migrateLegacyStructuredDocument.ts`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/canvas/state/migrateLegacyStructuredDocument.ts) and its nearest migration test |

Canvas/Yjs mutation, projection, history, and persistence direction remain owned by
[State and data flows](/development/architecture/state-flows).
