---
title: Canvas Writing
description: Render text into editable Canvas content at an original Cell coordinate.
---

`chardesk_canvas_write` belongs to the Canvas group in the [WebMCP contract](/development/architecture/webmcp).
With full-access local MCP, pass `canvasId` to write another Canvas without
changing the human's active Canvas. Omit it to write the active Canvas.
It writes to the active editable Freeform Canvas or current Slide page through
Canvas commands. Source-backed surfaces return `source_backed_canvas`; edit their
source with filesystem tools.

## Position and content

```json
{ "at": [100, 50], "content": "ABC\nDE", "writeMode": "patch" }
```

`at` is the required starting `[x,y]` in original Cell coordinates. Both coordinates
and the resulting endpoints must be safe integers. Content determines the footprint;
there is no input width, height, or scale.

The tool uses the same text renderer and current profile as Canvas text paste:
`auto`, `raw`, `ansi`, or `markdown`, including enabled features, Markdown wrapping,
theme colors, and tab expansion. [Canvas reading](/development/architecture/canvas-reading) discloses those
current settings. `writeMode` defaults to `patch`: ordinary whitespace is skipped,
so existing Cells are preserved; whitespace with a background, text attribute, or
link is still written. `replace` writes every rendered Cell, including ordinary
whitespace, and is the explicit mode for redrawing or clearing a rectangle.
Rendered non-whitespace spans replace characters and styles at their translated
Cell positions; unwritten positions stay unchanged. Existing backgrounds remain
unless the renderer supplies one. Slide overflow rejects the complete rendered
footprint before mutation.

Only rendered Cells persist; input text and its rendering profile are not retained
as editable source. This is not a source-document write API. Read reports the
current profile as a compact note: `mode`, `theme`, `wrap`, and Markdown feature
state; it does not expand every enabled feature unless a feature is disabled.

## Result and verification

The response contains an optional `canvasId`, the selected `writeMode`,
`bounds: [x,y,width,height]`, the envelope of written spans, and Cell counts for
`writtenCells` and `skippedWhitespaceCells`. Content with no written positions
returns `bounds: null` without creating history. Writes commit as one independently undoable operation and
do not change the user's camera, cursor, or selection. A Canvas or Slide switch
during rendering cancels the write; renderer failures never partially write.

Use returned bounds as the viewport of [Canvas reading](/development/architecture/canvas-reading). Its
coordinate rulers and sampled symbols are generated output, not write payloads.
Invalid input, missing Canvas, unavailable runtime, source-backed content, Slide
overflow, and execution failures return explicit error codes. Local CLI reader pages
do not register this write tool.
