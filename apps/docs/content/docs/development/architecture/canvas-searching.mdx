---
title: Canvas Searching
description: Locate rendered text in original Cell coordinates.
---

`chardesk_canvas_search` searches the active Canvas or current Slide page's rendered
Cells. It is read-only, works on source-backed projections, and does not move the
camera or change interaction. Source files, read rulers, style notes, and sampled
maps are not search content.

## Query and position

```json
{ "query": "Hello", "viewport": [0, 0, 100, 50] }
```

`query` is a case-sensitive literal, not a regular expression. It must contain a
non-whitespace character and no line breaks or control characters. Matches stay
within one row and use complete grapheme boundaries. Short gaps between stored
characters behave as spaces; large empty envelopes are never materialized.

Omit `viewport` to search all content. A supplied rectangle uses the same Cell
coordinates as [reading](/development/architecture/canvas-reading), but search always uses original
precision regardless of read's sampling `step`. Boundary-clipped glyphs do not match.

## Results and continuation

```json
{
  "canvasId": "example",
  "matches": [{ "viewport": [2, 18, 32, 5], "content": "…five space-padded rows…" }],
  "next": null
}
```

Results are ordered by the match's `y`, then `x`, with non-overlapping matches.
Each item contains only `viewport` and `content`: a 32×5 Cell window starting
8 Cells left and 2 rows above the match, shifted at safe coordinate limits.
`content` preserves spaces and newlines without borders, rulers, or style notes.
Words may be cropped; partially visible wide glyphs become blank Cells.
The input viewport limits matches, not their surrounding windows.

Read the returned viewport for styles, or enlarge it for more context. The
preview is not a whole-region replacement payload for [writing](/development/architecture/canvas-writing).

Each call returns at most 20 matches. Non-null `next` is the last returned match's
starting `[x,y]`, not the preview origin; pass it as `after` with the same query and viewport to continue
strictly after that position. Confirm `canvasId` has not changed. Calls observe
current content, not a shared snapshot; restart after an edit if consistency matters.
Empty results have `matches: []` and `next: null`.
