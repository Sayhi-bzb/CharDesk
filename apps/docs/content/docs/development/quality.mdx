## Verification lanes

| Lane | Scope |
| --- | --- |
| `check:quick` | Changed projects; risk-scoped Cell UI tests for local feedback |
| `check:pr` | Changed projects and consumers |
| `check:full` | Entire workspace, tests and production builds |

[`verification.mjs`](https://github.com/Sayhi-bzb/CharDesk/blob/main/scripts/quality/verification.mjs) owns selection and CLI options. Quick accepts explicit files independently of other edits; otherwise branch/worktree changes include deletions and both rename sides. PR/full reject explicit-file filtering. Dry runs explain the plan; executed tasks report wall time even on failure, with no cross-run cache.

[`verification-cell.mjs`](https://github.com/Sayhi-bzb/CharDesk/blob/main/scripts/quality/verification-cell.mjs) owns reviewed leaf suites and conservative fallback. Unknown/deleted Cell inputs select the whole module; shared contracts select Chromium and WebKit. Gallery CSS/configuration has explicit routes. Full package selections subsume leaf tests and browser suites share one launch. Cell-only quick defers types, guards and builds to PR/full unless requested explicitly; other products retain their policy. Quick feedback does not replace merge gates.

[Root test configuration](https://github.com/Sayhi-bzb/CharDesk/blob/main/vitest.config.ts) owns Node/JSDOM routing; [CI](https://github.com/Sayhi-bzb/CharDesk/blob/main/.github/workflows/ci.yml) owns the stable `Verify` status and parallel lanes. Native macOS input-service checks remain opt-in. Update an authority and its guard together when a contract changes.

## Agent navigation

Two benchmarks answer different questions:

- [Source navigation cases](https://github.com/Sayhi-bzb/CharDesk/blob/main/scripts/quality/agent-navigation-cases.mjs) measure GitNexus Top-3 implementation-owner recall against a 90% diagnostic target. A miss requires source/AST investigation; graph/source disagreement is an index issue.
- [Docs reading budget](https://github.com/Sayhi-bzb/CharDesk/blob/main/scripts/docs/check-reading-budget.mjs) measures the emitted index plus the cheapest path of at most two opened pages with pinned `js-tiktoken`/`o200k_base`. Fixed tasks retain owner paths and contract/evidence markers; catalogs count toward cost. The aggregate reduction target is 30% against the recorded pre-cleanup baseline. This is a deterministic retrieval/cost check, not an LLM accuracy evaluation.
